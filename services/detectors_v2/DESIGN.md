# detectors-v2 development design

Fixed before development evaluation. V1 modules, thresholds, and the live default remain unchanged. This directory is opt-in and outside the shared freeze. No TRAIL-B data or NexusBench TEST trace is decoded or evaluated.

- C1 calls the existing A1 adapter. A matched retrieval operation with a recorded error or an explicit error-output marker becomes TOOL_CALL, preserving its input/output and recorded error. Output-only errors receive ToolOutputError. Markers are nonempty JSON error, is_error=true, success=false, status error/failed/failure, or an explicit error/exception/traceback prefix. Successful retrieval remains retrieval.
- C2 parameters are exactly 3 calls, a 6-call window, and token Jaccard >=0.8, regardless of success. A same-tool triple must meet similarity for every pair (not just a transitive chain). Arguments use the frozen canonical JSON text, lowercase, punctuation/symbols replaced with word boundaries, and whitespace collapsed. Empty token sets compare as identical. Repetition counts executed TOOL_CALL/MEMORY_READ plus named or original-TOOL retrieval operations; this descriptive tool identity is separate from their source-evidence role. The frozen misfire rule still sees only actual TOOL_CALL/MEMORY_READ, including C1-restored errors.
- C4 keeps the original entity extractor, claim splitter, premise extraction/units, model/revision, and threshold. Before entity presence checks, entity strings and all retrieved source text are casefolded, accents removed by NFKD, thousands separators removed (1,000 -> 1000), punctuation/symbols replaced by boundaries, and whitespace collapsed. All entities may be found anywhere in retrieved text, rather than within one candidate premise. NLI inputs themselves are unchanged. A gate-forced zero makes the trace score exactly 1; exact min/max short-circuits avoid unnecessary inference without approximate pruning.
- C5 final evaluates CompleteTrace.final_output. C5 all_llm evaluates LLM outputs after a source operation, using only completed sources in that output's prefix. Existing native named retrieval-tool calls count as source operations, consistently with the frozen source extractor. Trace hallucination is the maximum over eligible outputs. The registered readability gate applies per target. No-output/no-source/no-claim cases abstain. A max score of 1 can short-circuit remaining targets exactly.

The only selection is higher pooled HALLUCINATION trace F1 on the 15 TRAIL dev traces plus 64 TRAIL-A members, using each scope's registered eligible denominator and excluding the known unconvertible A trace. F1 is 2TP/(2TP+FP+FN), undefined for denominator zero. An exact tie (or both undefined) chooses final; a defined score beats undefined. Both numbers, denominators, and abstentions are reported. No other parameters are tuned and NexusBench is not used for scope selection.

TRAIL reports the original class mapping and C3. C3 changes only the v2 LOOP prediction for Resource Abuse/Timeout Issues to v2 LOOP OR v2 TOOL_MISFIRE. V1 remains the original baseline in both tables. Other gold/category mapping, independent flags, Wilson intervals and abstention rules are unchanged. These are development numbers, not a new external result.

NexusBench uses only 359 DEV rows, filtered before constructing label records and before trace JSON decoding, then the existing detector_view. OTHER_FAILURE/RUN_ERROR are excluded from per-class metrics as in the original DEV contract. Report independent flags and priority-label per-class metrics; both five-class and original three-headline macro recalls. Flag a drop >0.02 in any displayed macro or any increase in false alerts per 1,000 NORMAL. This regression check never changes the C5 selection.

Exact pinned-model entailment memoization is private. TRAIL-A v1 outputs and entailments can reuse the previously validated post-hoc observations, whose inputs and frozen model are unchanged. No probabilities are approximated: cached scalar entailment is the same component consumed by the detector. Fresh v1 model calls return all original softmax components; cache entries without those components are not fabricated. All raw development records remain under the excluded private data directory.
