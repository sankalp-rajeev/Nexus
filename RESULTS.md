# Nexus Results

Single source of truth for every number Nexus claims. Each row links to a
committed file that records the provider, model, mock flag, date and git
commit. This file is generated by `python scripts/build_results_md.py`; do not
edit it by hand.

Rows marked **mock** come from deterministic test doubles and are not evidence
of real-model behaviour.

**95% CI column.** Clopper-Pearson, copied from the result file, unless the
cell says `W` (Wilson, computed here from the k/n shown). `-` means the source
records no count or proportion with an interval for that row. TEST rows are
text-only: their intervals come from the committed text reports named in the
Note column, because no TEST result file is opened to build this page.

- **51**: eligible failures: the 60 minus the 9 CONTEXT_BLEED failures with no observable harm. Denominator of 'gate promoted 25/51', 'generic 12/51', 'no patch 0/51' (a failure with no patch counts as not repaired and not promoted) (report line 61).
- **50**: usable v1_structured patches (10 failures got none: 7+1 CONTEXT_BLEED, 2 TOOL_MISFIRE) (report line 83).
- **48**: scored patches = 50 minus 2 patches on no-observable-harm CONTEXT_BLEED failures. Denominator of the RESULTS.md row (H1 32/48, gate 25) and of the 'distinct patches 48' (every v1 patch is distinct) (report line 91).
- **36**: other_fix scored patches (TOOL_MISFIRE 10, CONTEXT_BLEED 2, PLAN_DRIFT 12, LOOP_DETECTED 12) (report line 27).
- **12**: reverts_injection scored patches (HALLUCINATION: the patch removes the injected prompt) (report line 29).
